# 디자인 시스템

웨이핏 차량 앱 화면의 기준 문서. 새 화면을 만들 때 기존 화면을 눈대중으로 베끼지 말고 여기를 본다.
토큰은 `automotive/src/main/java/com/wayfit/wayfitpleos/ui/theme/` 한 곳에서 나온다.

차량 화면이라 일반 앱과 다른 전제가 있다.
- **한눈에 읽혀야 한다.** 운전자는 화면을 1~2초만 본다. 글자는 크게, 문장은 짧게.
- **다크 단일 테마.** 밤 운전 눈부심을 막고 Pleos 시스템 UI와 어울리게. 라이트 모드는 두지 않는다.
- **반복 애니메이션 금지.** 주행 중 시선을 끄는 깜빡임·맥박 효과를 쓰지 않는다 (진행 표시는 예외).

---

## 1. 색 (`Color.kt` · `WayfitColor`)

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `Brand` / `OnBrand` | 민트 `#2FD8A3` / `#032A1C` | 주요 버튼, 활성 탭, 진행·완료 표시, 혜택 문구 |
| `BrandSoft` | 민트 14% | 브랜드를 옅게 깐 타일·활성 탭 배경 |
| `Background` | `#0B0D10` | 화면 바탕 |
| `Surface` / `SurfaceRaised` / `SurfaceSunken` | `#15181D` / `#1D2128` / `#101318` | 카드 / 떠 있는 카드·보조 버튼 / 칩·움푹한 면 |
| `Border` | `#2A2F37` | 카드 테두리, 구분선 |
| `TextPrimary` / `TextSecondary` / `TextTertiary` | `#F3F5F7` / `#A4ACB7` / `#6C7480` | 본문 / 보조 / 라벨·비활성 |
| `Amber` | `#FFB547` | **주행 중·장시간 운전 등 주의** 상태에서만 |
| `Rose` | `#FF6B7A` | **만료·오류**에서만 |

### 규칙
- **브랜드는 민트 하나다.** 주요 동작·활성·완료는 전부 민트.
- **중립은 Ink 계열 하나다.** 회색을 새로 만들지 않는다.
- Amber·Rose는 **의미가 정해진 자리에서만** 쓴다. 장식이나 구분용으로 끌어다 쓰지 않는다.

## 2. 곡률 (`Dimens.kt` · `WayfitShape`)

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `Small` | 14dp | 타일(아이콘·이모지), 코드 입력 칸 |
| `Button` | 20dp | 버튼, 하단 탭 |
| `Card` | 28dp | 카드, 쿠폰 티켓 |
| `Pill` | 50% | 상태 칩, 정보 칩 |

이 네 가지 외 값을 쓰지 않는다.

## 3. 높이(깊이)

2단계만 쓴다 (`WayfitCard(level = …)`).

| 단계 | 모양 | 쓰는 곳 |
| --- | --- | --- |
| `Flat` | `Surface` + 1dp `Border` | 화면에 붙은 정보 (경로 패널, 단계 목록) |
| `Floating` | `SurfaceRaised` + 민트 테두리 + 민트 그림자 | **운전자가 결정해야 하는 것** (추천 카드) |

다크 화면에서는 회색 그림자가 보이지 않으므로, 떠 있는 것은 브랜드 빛 번짐으로 구분한다.

## 4. 간격·크기 (`WayfitSpace` · `WayfitSize`)

- 간격은 8dp 격자: `XS 8 · S 12 · M 16 · L 24 · XL 32 · XXL 48`
- 버튼 높이 **96dp** (AAOS 최소 터치 76dp보다 크게), 하단 탭 80dp
- 본문 최대 폭 760dp. 화면 폭이 1100dp 이상(Pleos 가로 2칸)이면 왼쪽에 경로 패널을 띄운다.

## 5. 타이포그래피 (`Type.kt`)

| 스타일 | 크기 | 쓰는 곳 |
| --- | --- | --- |
| `displayMedium` | 46sp ExtraBold | **혜택 문구**, 남은 거리 숫자 — 화면에서 가장 먼저 읽혀야 하는 것 하나 |
| `headlineLarge` | 34sp Bold | 화면 제목 |
| `titleLarge` | 28sp SemiBold | 매장명, 카드 제목 |
| `bodyLarge` | 22sp | 본문 |
| `labelLarge` | 24sp Bold | 버튼 |
| `labelMedium` | 18sp Medium | 칩, 라벨, 보조 정보 |

- 한글은 `widget/Text.kt`(어절 단위 줄바꿈 래퍼)를 쓴다. material3 `Text`를 직접 쓰지 않는다.
- 폰트는 시스템 한글 폰트를 쓴다 (Pleos 기기 간 동일).

## 6. 컴포넌트 (`widget/`)

| 컴포넌트 | 용도 |
| --- | --- |
| `PrimaryButton` / `SecondaryButton` | 누르면 0.96배로 살짝 눌림. 한 화면에 Primary는 하나 |
| `WayfitCard` | 카드 (Flat / Floating) |
| `StatusChip` / `InfoChip` | 상태(색 있음) / 정보(중립) |
| `EmojiTile` / `IconTile` | 카테고리·상태 아이콘 타일 |
| `TicketCard` | 쿠폰 (홈 파인 티켓 + 코드 스텁) |
| `RouteStrip` | 현재 위치 → 들를 곳 → 목적지 한 줄 경로 |
| `DrivingGate` | 주행 중 정차 전용 화면 가리기 |

화면에서 버튼·카드를 인라인으로 새로 만들지 않는다. 필요하면 여기에 추가한다.

## 7. 문구

- 해요체, 한 문장. 주행 중 화면은 10자 안팎으로.
- 운전자에게 지시하지 않고 제안한다: "들를까요?", "정차 후 이용할 수 있어요".
- 숫자는 단위와 함께 짧게: `1.2km 앞`, `약 3분 우회`, `779m 남음`.
